# Schema Evolution Edge Cases

## Purpose

This note lists the edge cases of the schema evolution feature, on the `evolution` branch: a name reuse, a case object,
a case class that becomes a case object, a declaration that the checks must reject. For each case, it gives the status and the
test that verifies it. The words follow the [ubiquitous language](UBIQUITOUS_LANGUAGE.md).

The status of a case is one of:

- **Works**: the evolution needs only its annotations.
- **Constraint**: the evolution works under a condition, which the table gives.
- **Impossible**: the feature does not support the evolution. The table gives the workaround, if one exists.
- **Surprise**: the behavior is correct, or acceptable, but the developer may not expect it.

A test reference is `TestClass` "test name". The tests of the `evolution` package are in
`modules/flink-common-api/src/test`, next to the tests of the same kind. `EvolutionRestoreTest`, in
`modules/flink-1-api/src/test`, restores a savepoint in a MiniCluster. `SelfEvolvingCaseObjectTest` is Scala 3 only.

## 2. Cases with a constraint, or impossible

| Case                                                                                                                                 | Status                                                                                                                                                                                                                                                                                                                                                          | Test                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|--------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| A class takes a former class name, after a rename or a deletion.                                                                     | Constraint: the class declares `@version` equal to or higher than the `since` of the rename or of the deletion. Else the submission check fails with `FormerClassConflictException`.                                                                                                                                                                            | `EvolutionRenamedTest` "deserialize a subtype that reuses the former name of another subtype"; `EvolutionTest` "deserialize a subtype that reuses the name of a subtype deleted at a lower version"; `EvolutionsRegistryTest` "fail every lookup when a class reuses a former class name without a higher version"                                                                                                                                                                            |
| The class that takes the name has no evolving companion.                                                                             | Constraint: it has the version 0, so the check always fails.                                                                                                                                                                                                                                                                                                    | `EvolutionsRegistryTest` "count a class that reuses a former class name without an evolving companion as unversioned"                                                                                                                                                                                                                                                                                                                                                                         |
| Two fields exchange their names in one version.                                                                                      | Impossible with `@renamed`: the first rename finds its current name taken. Workaround: `@postEvolution` exchanges the values.                                                                                                                                                                                                                                   | `EvolutionTest` "not exchange the names of two fields with two @renamed in one version", "exchange the values of two fields with a post-evolution mapper"                                                                                                                                                                                                                                                                                                                                     |
| A field renamed to the name of a field that is not declared deleted.                                                                 | Impossible: the plan fails.                                                                                                                                                                                                                                                                                                                                     | `EvolutionTest` "not migrate a field renamed to the name of an undeclared deleted field"                                                                                                                                                                                                                                                                                                                                                                                                      |
| A case class becomes a case object with the same name, or a case object becomes a case class.                                        | Impossible with `@renamed`: the two serializers differ. Workaround: `@deletedClasses` on the sealed trait, `@postEvolution` that maps `null` to the case object, and `@version(1)` on the case object.                                                                                                                                                          | `CaseObjectEvolutionTest` "replace a case class by a case object of the same name with a deletion and a post-evolution mapper"                                                                                                                                                                                                                                                                                                                                                                |
| An enum value gets parameters.                                                                                                       | Impossible: an enum value without parameters and an enum value with parameters have different serializers. Workaround: delete the value, add a value, `@postEvolution`.                                                                                                                                                                                         | `Scala3EnumTest` "resolve the schema compatibility of an enum value that gets parameters as incompatible"                                                                                                                                                                                                                                                                                                                                                                                     |
| `@transformed` on a field whose former type is a deleted class.                                                                      | Impossible: the restored serializer of a deleted class builds no instance, so the field mapper gets an exception or `null`. Keep the former class, renamed if necessary. Without `@transformed`, the compatibility result is incompatible.                                                                                                                      | `EvolutionTest` "not transform a field whose former type is a deleted class"                                                                                                                                                                                                                                                                                                                                                                                                                  |
| A subtype changes its sealed trait.                                                                                                  | Constraint: `@deletedClasses` on the former sealed trait, and `@version(1)` on the subtype. See also section 3.                                                                                                                                                                                                                                                 | `SubtypeVersionTest` "change the sealed trait of a subtype with a version above the deletion"                                                                                                                                                                                                                                                                                                                                                                                                 |
| A versioned case object that no evolving companion declares: outside a sealed trait, or under an unversioned sealed trait.           | Impossible: the derivation does not compile. In Scala 3, a case object can be its own evolving companion.                                                                                                                                                                                                                                                       | `EvolutionValidationTest` "reject the derivation of a versioned case object that no evolving companion declares"                                                                                                                                                                                                                                                                                                                                                                              |
| `@version` on an enum value.                                                                                                         | Impossible: the macros reject it. An enum value has the version of its enum.                                                                                                                                                                                                                                                                                    | `EvolutionMacroEnumTest` "not compile a version on an enum value"                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `@deletedFields` with the name of a field that the current schema keeps.                                                             | Impossible: the plan fails with "Field 'kept' is deleted, but the current schema contains it".                                                                                                                                                                                                                                                                  | `EvolutionMacroTest` "report a deleted field that the current schema keeps"                                                                                                                                                                                                                                                                                                                                                                                                                   |
| A relative former class name that resolves to the current class, after a rename from a package into an enclosing object.             | Impossible: the submission check fails with "The former class name … resolves to … itself. Write the absolute former class name".                                                                                                                                                                                                                               | `EvolutionsRegistryTest` "fail every lookup when a former class name resolves to the current class"                                                                                                                                                                                                                                                                                                                                                                                           |
| A case object outside a sealed trait is its own evolving companion.                                                                  | Constraint: Scala 3 only. In Scala 2.13, the compiler fails with a cyclic reference: "no progress in completing object".                                                                                                                                                                                                                                        | `SelfEvolvingCaseObjectTest` "resolve the former name of a case object that is its own evolving companion"                                                                                                                                                                                                                                                                                                                                                                                    |
| An unversioned subtype declares an evolution annotation.                                                                             | Impossible: its snapshot records the version 0, which cannot tell its data apart. Only an enum value accepts `@renamed`.                                                                                                                                                                                                                                        | `EvolutionValidationTest` "reject an evolution annotation on an unversioned subtype"                                                                                                                                                                                                                                                                                                                                                                                                          |
| A rollback.                                                                                                                          | Impossible: the compatibility result is incompatible.                                                                                                                                                                                                                                                                                                           | `EvolutionCompatibilityTest` "resolve the schema compatibility of a sealed trait after a rollback as incompatible", "resolve the schema compatibility of a case class after a rollback as incompatible"; `Scala3EnumTest` "resolve the schema compatibility of an enum after a rollback as incompatible"                                                                                                                                                                                      |
| A field added without `@added`. A type changed without `@transformed`. A subtype or an enum value deleted without `@deletedClasses`. | Impossible: the compatibility result is incompatible.                                                                                                                                                                                                                                                                                                           | `ScalaCaseClassSerializerSnapshotTest` "be incompatible when a field is appended to the end without @added"; `EvolutionCompatibilityTest` "resolve the schema compatibility of Click v0 with a field type changed without annotation as incompatible", "resolve the schema compatibility of a sealed trait with a subtype deleted without annotation as incompatible"; `Scala3EnumTest` "resolve the schema compatibility of an enum with a value deleted without annotation as incompatible" |
| A savepoint written before release 2.4.0.                                                                                            | Constraint: the restored serializer reads the fields by position. A case class declaring field evolutions or a post-evolution mapper for this data is incompatible, as an added field. Restore it once with release 2.4.0, then take a savepoint. The snapshot of a sealed trait or of an enum records no class name: its members keep the standard resolution. | `EvolutionCompatibilityTest` "resolve the schema compatibility of a case class snapshot recording no field name with evolutions as incompatible"; `EvolutionCompatibilityTest` "resolve the schema compatibility of a case class snapshot recording no field name with an added field as incompatible"; `SubtypeVersionTest` "migrate a renamed subtype from a snapshot of format version 2"                                                                                                  |
| The key type of a keyed stream evolves, even with reordered fields only.                                                             | Impossible: Flink accepts only a key serializer that is compatible as is. The restore fails with `StateMigrationException`: "The new key serializer (…) must be compatible with the previous key serializer".                                                                                                                                                   | `EvolutionRestoreTest` "not restore a keyed state whose key type declares an evolution"                                                                                                                                                                                                                                                                                                                                                                                                       |
| The user key type of a `MapState` evolves, with RocksDB.                                                                             | Impossible: Flink 1.20 refuses it, "migration for MapState currently only allows value schema evolutions".                                                                                                                                                                                                                                                      | None: the tests have no RocksDB dependency.                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `@deletedClasses` on an enum, with a `since` above the version of the enum.                                                          | Constraint: an enum deletes its values in its own versions. A sealed trait has no upper bound, because the `since` counts in the versions of the deleted subtype.                                                                                                                                                                                               | `EvolutionMacroEnumTest` "not compile a declaration deleting an enum value since a version above the one of its enum"; `SubtypeVersionTest` "migrate a deleted versioned subtype"                                                                                                                                                                                                                                                                                                             |

## 3. Cases that can surprise the developer

| Case                                                                                                 | Behavior                                                                                                                                                                        | Test                                                                                                                                                                                                       |
|------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| The former class stays in the source code after `@renamed` or `@deletedClasses`.                     | The submission check fails: "used by X at version 0". Delete the former class, or give it a higher version.                                                                      | `EvolutionsRegistryTest` "count a class that reuses a former class name without an evolving companion as unversioned", "find a case object that reuses a name deleted without the $ ending its class name" |
| A subtype changes its sealed trait.                                                                  | Every state that holds the subtype at version 0 reads it as deleted, not only the state of the former sealed trait.                                                              | `SubtypeVersionTest` "change the sealed trait of a subtype with a version above the deletion", last assertion                                                                                         |
| The `since` of a renamed or deleted subtype.                                                         | It counts in the versions of the subtype, not in the versions of the sealed trait.                                                                                               | `SubtypeVersionTest`                                                                                                                                                                                       |
| A `since` of `@deletedClasses` higher than the versions of the deleted class.                        | The deletion applies to every version below `since`. Only a name reuse makes the exact `since` matter.                                                                           | `EvolutionMacroTest` "apply a deletion whose since is higher than the versions of the deleted class"                                                                                                    |
| The field mapper of `@transformed` expects another type than the former type of the field.           | The compatibility result is compatible after migration, then the first record throws `ClassCastException`. The resolution cannot check the input type of the mapper.             | `EvolutionTest` "fail at the first record when the mapper of a transformed field expects another type"                                                                                             |
| `@deletedFields` with a name that the former data does not contain.                                  | The deletion is ignored.                                                                                                                                                         | `EvolutionTest` "ignore a deleted field not found when deserializing Click v0"                                                                                                                             |
| `@deletedClasses` with a class name that never existed.                                              | The deletion is ignored. The real error appears at the restore: "Former subtype 'X' is not in …".                                                                                | `EvolutionCompatibilityTest` "resolve the schema compatibility of a sealed trait with a subtype deleted without annotation as incompatible", for the symptom                                               |
| `@postEvolution` on a sealed trait, and a `null` record.                                             | Only a deleted instance gives `null` to the mapper. A `null` record reads as `null`, without migration.                                                                          | `EvolutionTest` "not give a null record to the post-evolution mapper of a sealed trait"                                                                                                            |
| A mapper whose initialization fails.                                                                 | Every lookup of the class loader fails with the first failure, which names the ADT.                                                                                              | `EvolutionsRegistryTest` "fail every lookup with the first failure of a mapper initialization"                                                                                                             |
| The companion scan misses an evolving companion.                                                     | The lookup throws `IllegalStateException`. It does not give empty evolutions.                                                                                                    | `EvolutionsRegistryTest` "fail to look up a class whose evolving companion the scan did not find"                                                                                                          |
| A former enum value that the current enum does not contain, without annotation.                      | `MigrationException`, not `null`.                                                                                                                                                | `Scala3EnumValueSerializerSnapshotTest` "fail to deserialize a former enum value that the current enum does not have"                                                                                      |
